📌 Projeto EBOOK Gerado por I.A.s
Este repositório contém um eBook digital criado com auxílio de ferramentas de Inteligência Artificial, reunindo conteúdo estruturado e imagens geradas a partir de prompts específicos. O objetivo do projeto é mostrar como a IA pode facilitar a criação de eBooks completos, didáticos e visuais.

 📌 Projeto EBOOK Gerado por I.A.s
[Clique aqui para ler o eBook](./ebook_ia.pdf)



💻 Tecnologias utilizadas
ChatGPT – Geração de textos e conteúdo do eBook
MidJourney – Criação de imagens e ilustrações
PowerPoint / Google Docs / Canva – Diagramação final do eBook

🧠 Prompts Utilizados
ChatGPT
Ação Prompt
Título	Crie um título de eBook sobre IA generativa aplicada ao marketing digital, o título deve ser curto, épico e chamativo, me liste 5 variações.
Conteúdo	Faça um texto para eBook sobre marketing digital, explicando conceitos, exemplos práticos,  e passo a passo, de maneira simples e didática. Inclua títulos sugestivos por tópico, checklists e exemplos de prompts.
MidJourney
Ação Prompt
Capa Design moderno de capa para eBook sobre Marketing Digital, cores vibrantes em azul  roxo, laranja e azul, ícones de redes sociais, computador e gráficos. Estilo minimalista e profissional.

✨ Features
Conteúdo gerado via ChatGPT
Imagens e ilustrações geradas via MidJourney
Estrutura completa de eBook: capa, índice, capítulos, checklists, gráficos e conclusão motivacional.

📚 Materiais
Imagens utilizadas em assets
PDF gerado durante o projeto
🛠️ Instruções de execução
Utilizei os prompts acima nas ferramentas sugeridas para gerar os textos e imagens.
Usei uma ferramenta de edição de documentos (PowerPoint, LibreOffice, Canva ou Google Docs) para diagramação final do eBook.
Salve como PDF ou outro formato desejado para distribuição.
